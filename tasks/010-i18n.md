Status: todo

Estonian and English UI, switchable per user (`docs/product.md`, "Languages").

## Acceptance criteria

- [ ] Paraglide JS, installed by hand, with locales `et` and `en`; messages in
      `messages/`; compiled output gitignored and formatter-ignored.
- [ ] The locale is kept in a cookie; whether it is also stored per user is decided and
      recorded, and the open question in `architecture.md` is closed.
- [ ] The `<html lang>` attribute follows the locale.
- [ ] The compile step runs before tests and builds, so a fresh clone works.
